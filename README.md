Sentiment Analysis using Machine Learning
 
Overview
 
This project implements a basic Sentiment Analysis model that classifies text reviews as positive or negative using Machine Learning techniques. It demonstrates how Natural Language Processing (NLP) can be applied to analyze textual data.
 
 
 
Objective
 
The objective of this project is to build a model that can automatically detect the sentiment of a given text input.
 
 
 
Technologies Used
 
- Python
- Pandas
- NumPy
- Scikit-learn
 
 
 
Methodology
 
- Created a dataset of sample text reviews
- Converted text into numerical form using TF-IDF Vectorizer
- Split data into training and testing sets
- Trained the model using Logistic Regression
- Evaluated model performance using accuracy
 
 
 
How to Run
 
1. Open the notebook file (".ipynb") in Jupyter Notebook or Google Colab
2. Run all the cells step-by-step
3. The model will train and display accuracy
4. Test the model with your own input
 
 
Output
 
- Displays model accuracy
- Predicts sentiment (positive/negative) for given input
 
Sample Output
 
Example:
 
- Input: "This movie was fantastic"
- Output: Positive
